# The Wire Room
An independent, AI-powered news outlet summarizing global news based on a diverse portfolio of reliable sources, ensuring neutrality and objectivity.

Sections: Briefing, Conflicts, Money, Politics. Regions: Worldwide, Europe, Americas, Asia & Middle East, Africa. Languages: English, Русский, Français, Deutsch, Español, 中文, العربية.

`index.html` is the site; `news.json` holds the current edition and is refreshed several times a day.
